## 2026-06-14 - [Algorithmic and Environment Optimization]
**Learning:** O(M) lookups (like `Array.indexOf`) inside O(N log N) sorting comparisons create a measurable bottleneck as datasets grow (~1,000+ items). Additionally, environment-specific CI (Cloudflare Workers) may reject ES2020+ features like optional chaining (`?.`) and static class fields even if local syntax checks pass.
**Action:** Always pre-calculate comparison weights into a Map (or `Object.create(null)`) before sorting. Avoid ES2020 features in this codebase to maintain CI compatibility. Use `textContent` instead of `innerHTML` for simple text updates to gain a minor but measurable rendering boost.
