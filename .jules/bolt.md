## 2025-05-15 - Large Gallery Performance Optimization
**Learning:** In galleries with >1,000 items, `innerHTML` template strings in a loop cause significant performance degradation due to repeated HTML parsing. Algorithmically, $O(N)$ sorting using `indexOf` in a loop creates an $O(N^2)$ bottleneck that becomes noticeable at this scale. Additionally, uncapped GSAP staggers can lead to extremely long "entrance" sequences where the last items appear minutes after the first.
**Action:** Use `document.createElement` for iterative item creation, `replaceChildren()` for high-performance DOM clearing, and a `Map` for $O(1)$ priority lookups during sorting. Always cap GSAP stagger `amount` and CSS transition delays (e.g., 1.5s - 2.0s max) to ensure a responsive UI regardless of list size.
