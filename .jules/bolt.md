## 2026-06-14 - [Algorithmic and Environment Optimization]
**Learning:** O(M) lookups (like `Array.indexOf`) inside O(N log N) sorting comparisons create a measurable bottleneck as datasets grow (~1,000+ items). Additionally, environment-specific CI (Cloudflare Workers) may reject ES2015+ features including `class`, `const`, `let`, arrow functions, template literals, spread operators, and trailing commas in object/array literals or class methods, even if local syntax checks pass. A trailing comma in a class method definition (illegal in standard JS) can cause silent build failures or syntax errors.
**Action:** Always pre-calculate comparison weights into a Map (or `Object.create(null)`) before sorting. Avoid ALL ES2015+ features in this codebase (use `var`, `function`, prototype-based inheritance) to maintain strict legacy CI compatibility. Rigorously check for and remove all trailing commas, especially those introduced by automated refactoring or existing technical debt in related files. Use `textContent` instead of `innerHTML` for simple text updates to gain a minor but measurable rendering boost.
